Scaffold Tracking Number generation Local SetUp Softwares

1. Java 17
2. Maven
3. Spring Tool Suite
4. MongoDB


Local Setup Steps:

1. Clone the source code from the git clone url (https://github.com/BILDON/Scaffold/tree/valuelabs_task/ScaffoldMain).
2. Import the project the as existed maven project into the sts application.
3. Select the pom.xml file and click on the finish.
4. Set up the mongodb url in the application.properties file.
5. Make sure the database name is "tracking".
6. Make sur the collections name is "trackingNumber".
7. Run the application using the ScaffoldMainApplication.class.
